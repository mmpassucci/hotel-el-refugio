# 🏨 Hotel El Refugio

Breve descripción del proyecto.  
Sitio web institucional de un hotel de fantasía llamado Hotel El Refugio. El sitio web fue pensado para brindar información sobre el alojamiento, sus habitaciones, los servicios que ofrece y facilitar el contacto y las reservas de los huéspedes.

Elegí este proyecto pensando en el lugar en el que vivo, donde muchos hoteles no tienen página web y sólo utilizan redes sociales para mostrar las instalaciones y los servicios. Esta web está pensada para ofrecer un sitio institucional dentro del rubro, que se complemente con las redes sociales y al mismo tiempo que brinde seriedad y confianza al usuario, quien puede ver las instalaciones, la ubicación y los servicios del hotel, y hacer una reserva. 

Las dificultades al hacer este proyecto fueron muchas, integrar todos los conocimientos en primer lugar, hacer los HTML lo mejor estructurados posibles, trabajar con SASS que fue todo un desafío, revisar una y otra vez que todo funcione y se cumplan los criterios solicitados. 
---
## 📋 Descripción del proyecto

**Hotel El Refugio** es un sitio web institucional desarrollado como proyecto final del curso Desarrollo Web Flex de CoderHouse. 
El objetivo del proyecto es crear una página web moderna, accesible y responsive que permita a los usuarios:

- Conocer el Hotel El Refugio.
- Consultar información sobre las habitaciones.
- Conocer los servicios ofrecidos.
- Visualizar algunas fotografías del establecimiento.
- Consultar las actualizaciones en una sección de Novedades.
- Realizar consultas o solicitudes de reserva.
- Acceder a las redes sociales del hotel.
- Encontrar información de contacto y ubicación del hotel.
---
## 📋 Características del proyecto

 -  Diseño responsive.
 -  Navegación entre las diferentes páginas del sitio.
 - Sección de presentación del hotel.
 - Información sobre los servicios que ofrece el hotel -tipo de habitaciones, wifi, parking, pileta y spa, acepta mascotas, desayuno incluido-
 - Imágenes del hotel.
 - Sección de novedades para  comunicar promociones y nuevos servicios.
 - Formulario de reservas/contacto.
 - Integración de Google Maps para mostrar la ubicación.
 - Animaciones y efectos hover.
 - Uso de variables, mixins y extend en SCSS.
 - Organización de estilos mediante partials de SCSS.
 - Implementación de Bootstrap en una sección para mostrar la habilidad y no abusar con el recurso.
 - Uso de media queries para adaptar el diseño a diferentes resoluciones.

---
## 🛠️ Tecnologías utilizadas

Las tecnologías y herramientas utilizadas en este proyecto son:
HTML5 — estructura y contenido de las páginas.
CSS3 — estilos y diseño visual.
SCSS/Sass — organización y reutilización de estilos mediante variables, partials, mixins, extend y anidación.
Bootstrap 5 — utilizado en la seccion correspondiente del proyecto que es en NOVEDADES.
Google Fonts — tipografías: "Playfair Display" (H1 y titulos),"Montserrat", sans-serif (subtitulos y párrafos)
Google Maps — integración del mapa de ubicación.
Git — control de versiones.
GitHub — almacenamiento y publicación del proyecto.
Vercel — almacenamiento y ejecucion del proyecto.
